# Wfarhali Agent — 3-minute demo video script

Recording setup: the app runs on the laptop (`localhost:8000`, Chrome full screen, window ~1366×768), screen recorded with OBS or `Win+Alt+R`. Open the page before recording and run each scenario once so the catalogue is warm. Narration can be spoken in English (recommended for the jury) or in Darija with English captions; both versions are given. Target length: 2:50.

## Before recording
- `.env` on the laptop: `WFAGENT_LLM=meta`, `WFAGENT_STT=meta`, `WFAGENT_SEGMENT=meta`, `WFAGENT_CATALOGUE=wfarhali`.
- Record the Darija voice note on the phone first, in a quiet room, speaking naturally but a little slowly (e.g. «راني نحوس على بوت شتاء أسود مقاس 39 وفاست، الميزانية 2 ملاين»); copy the file to the Desktop and test it once with the note button.
- Open the GitHub commit list and `agent/segment.py` in tabs beforehand for the "proof of new work" shot (the repository must be public by then, or record it while logged in).
- Choose the product photo (a real bag or pair of shoes, well lit) and test it once.
- Run the swap scenario once: if the second jacket does not differ, pick another example.
- Close other tabs; hide bookmarks (`Ctrl+Shift+B`).
- If a step takes more than 10 seconds, cut the wait in editing; keep the typing dots for a second or two.
- Pacing: mandatory first sentence, greeting and problem (0:40), voice + impact (0:40), swap + question (0:35), photo (0:25), confirm (0:13), proof of new work (0:15), close (0:12). The very first spoken sentence must be the one about what existed before and what was built.

## Honesty notes (say nothing that is not true)
- Voice: say "Muse Voice Transcribe turns the voice into text" only after the voice-note test works on the laptop. If it does not, record the scenario with text and say "typed or spoken".
- Photo: say "SAM 3.1 locates the item" only if the cut-out appears in the recording.
- Do not claim orders are placed automatically: the team confirms on WhatsApp.
